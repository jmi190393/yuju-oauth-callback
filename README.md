# 💰 Finanzas personales y familiares

Sistema de finanzas personal y familiar: presupuesto, gastos, suscripciones, MSI, metas, inversiones y facturación (CFDI).

> **Nota sobre el nombre del repositorio**: este repo se llamaba `yuju-oauth-callback` por un uso anterior sin relación con este proyecto (Yuju es un tema de trabajo, no de este sistema). El proyecto se llama **Finanzas personales y familiares**. Se recomienda renombrar el repositorio en GitHub a `finanzas-familiares` (Settings → General → Rename); GitHub redirige la URL vieja automáticamente.

> ⚠️ **Este repositorio debe permanecer privado**: contiene información financiera personal.
